Учебный проект по Django с HTML блочной версткой и вставкой информации при помощи 
механизма view .css стилями. Код писался с активным применением таких ИИ как DeepSeek и Le Chat.

Проект представляет собой вебс-сайт, посвященный рыбалке. С помощью этого веб-сайта можно найти интересующий вид рыбы 
и узнать о нем множетсво информации, в том числе с какими приманки лучше всего идти за крупным уловом. Также есть список
всех приманок, по которому можно узнать что какую ещё рыбу можно поймать на одну приманку. 

На сайт можно добавлять свои виды рыбы и приманок с фотографиями и подробным описанием через специальные формы. 
При добавлении новой карточки с видом рыбы можно указать приманки, на которую она ловиться. Эта информация также
отобразиться в карточках выбранных приманок. 

Сайт состоит из 3 основных страниц: главная, список рыб и список приманок, между которыми можно перемещаться. 
На страницах списков изображены карточки с кратким описанием вида рыбы/приманки и фото. Фото брались из открытых
источников.
